# Introdução
O .NET MAUI (Multi-platform App UI) é um framework da Microsoft para o desenvolvimento de aplicativos multiplataforma, permitindo a criação de apps para Android, iOS, Windows e macOS com um único código base em C# e .NET.

O .NET MAUI foi anunciado oficialmente pela Microsoft em maio de 2020, durante o evento Microsoft Build 2020.

Ele foi lançado para produção junto com o .NET 6, em maio de 2022, marcando a evolução do Xamarin.Forms para um framework multiplataforma mais moderno e integrado ao ecossistema .NET.

Desde então, o .NET MAUI recebe melhorias contínuas, com versões aprimoradas no .NET 7 (2022) e .NET 8 (2023), trazendo mais estabilidade, desempenho e novos recursos. 🚀

# Principais Características

- Código Único – Compartilha lógica e UI entre plataformas.
- Baseado no Xamarin – Evolução do Xamarin.Forms com melhorias no desempenho e suporte a mais plataformas.
- Suporte a MVU e MVVM – Flexibilidade para diferentes padrões de arquitetura.
- Integração com Blazor – Permite usar componentes Blazor para criar interfaces nativas.
- Acesso a APIs Nativas – Suporte direto a funcionalidades como câmera, GPS e notificações.
