.NET MAUI (Multi-platform App UI) é um framework da Microsoft para o desenvolvimento de aplicativos multiplataforma, permitindo a criação de apps para Android, iOS, Windows e macOS com um único código base em C# e .NET.
Principais Características

- Código Único – Compartilha lógica e UI entre plataformas.
- Baseado no Xamarin – Evolução do Xamarin.Forms com melhorias no desempenho e suporte a mais plataformas.
- Suporte a MVU e MVVM – Flexibilidade para diferentes padrões de arquitetura.
- Integração com Blazor – Permite usar componentes Blazor para criar interfaces nativas.
- Acesso a APIs Nativas – Suporte direto a funcionalidades como câmera, GPS e notificações.
Casos de Uso

- Aplicativos empresariais multiplataforma
- Apps com interface rica e integração nativa
- Aplicativos que reutilizam código entre mobile e desktop
